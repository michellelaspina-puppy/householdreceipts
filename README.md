# Household Receipts

Because someone has to keep the receipts.

Household Receipts 2.0 is a mobile-first household labor tracking app. It stores data locally in the browser, supports photo proof, compares partner contributions, and exports spreadsheet or printable PDF reports.

## Features

- Daily task logging with category, time, notes, and optional photo proof
- Partner contribution logging
- Household balance dashboard
- Daily, weekly, and monthly reporting
- Category summaries
- CSV spreadsheet export
- Printable PDF export
- Local/private browser storage

## Deploy

This is a static site. Cloudflare Pages can deploy it directly from the repository root.
